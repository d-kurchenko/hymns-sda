# Google Play artwork

Редактируемые исходники постеров приложения «Гимны АСД». В Git сохраняются
конфигурация, генератор, оригинальные скриншоты и шрифт с лицензией.
Готовые PNG, предпросмотры и ZIP создаются в `out/`, которая включена в `.gitignore`.

Отдельные AI-варианты Feature graphic (1024 × 500) и промпты для их обновления
описаны в [feature-graphics.md](feature-graphics.md).

## Генерация

Требуется Python 3.10+ и Pillow. Установка в локальное окружение:

```sh
python3 -m venv docs/google-play/.venv
source docs/google-play/.venv/bin/activate
python -m pip install -r docs/google-play/requirements.txt
npm run assets:google-play
```

После установки достаточно активировать окружение и запустить последнюю команду.
Если Pillow уже установлен в используемом Python, окружение создавать не нужно.
Приложение и браузер для генерации из сохранённых скриншотов не нужны.

Дополнительные команды:

```sh
# Только телефон
npm run assets:google-play -- --only phone

# Проверка конфигурации, файлов и размеров без экспорта
npm run assets:google-play -- --check

# Запуск из любой папки через абсолютный путь к render.py
python3 /path/to/hymns-sda/docs/google-play/render.py
```

## Как актуализировать

1. Откройте `config.json` и поменяйте `title` и `subtitle` в нужном элементе `slides`.
   `\n` задаёт желаемый перенос заголовка. Генератор также переносит слова сам;
   на вертикальных постерах помещаются две строки заголовка и одна строка подписи.
   На горизонтальных — две строки заголовка и до двух строк подписи.
   Если текст слишком длинный, генератор просит сократить его, а не обрезает.
2. Замените PNG/JPEG в `screenshots/` либо измените пути в `slides[].screenshots`.
   Пути задаются относительно этой папки (`docs/google-play`), включая `--config`.
3. Запустите `npm run assets:google-play`.
4. Проверьте `out/preview-phone.jpg` и другие `out/preview-*.jpg`.
5. Загружайте PNG из папок категорий или распакуйте `out/google-play-posters.zip`.

Скриншоты показываются целиком, сохраняют пропорции и автоматически вписываются
в рамку. Поэтому их разрешение и соотношение сторон можно менять. Лучше брать
вертикальные снимки для телефона/планшетов и горизонтальные для Desktop/XR.
Для более чёткого интерфейса используйте оригинальные снимки с устройства;
увеличение маленького скриншота не добавляет ему детализации.

Добавить постер можно новым элементом `slides` с уникальным `id` и тремя путями
к снимкам (`phone`, `tablet`, `wide`). Цвета, имя приложения, подпись внизу,
шрифт и иконка также задаются в `config.json`. Компоновка находится в `render.py`.

## Категории и результат

- `phone/`: 1080 × 1920, 9:16.
- `tablet-7-inch/`: 1440 × 2560, 9:16.
- `tablet-10-inch/`: 2160 × 3840, 9:16.
- `desktop/`: 3840 × 2160, 16:9.
- `android-xr/`: 3840 × 2160, 16:9.

По умолчанию — по четыре PNG в каждой категории: главная, общий поиск, текст
псалма и избранное. Всего 20 постеров. Экспорт проверяет размеры, пропорции и вес. Все PNG — RGB, без
прозрачности. `out/manifest.json` содержит размеры и вес готовых файлов.
ZIP содержит только постеры; исходники и предпросмотры в него не попадают.
При повторном экспорте удалённые из конфигурации постеры убираются из
генерируемой категории и архива.

По приведённым требованиям Google Play для Desktop/XR минимум четыре картинки;
текущая серия соответствует этому количеству. Одна и та же горизонтальная композиция применяется
к Desktop и XR; на физических XR-устройствах снимки не делались.

## Исходные снимки

Снимки сделаны из локального веб-приложения: русский интерфейс, светлая тема,
оба языка сборников, стандартный размер текста. Поиск: «благодать»; текст:
«72. Как дивна благодать Твоя» (`/books/0/72`). Избранное: шесть сохранённых
псалмов из четырёх сборников, режим «Список», сортировка «Сначала новые».

- Телефон: окно 440 × 700 CSS px.
- Планшет: окно 768 × 1024 CSS px.
- Горизонтальные снимки: окно 1100 × 800 CSS px.

Маркетинговые надписи используют включённый в исходники вариативный шрифт
Adwaita Sans; лицензия находится рядом в `assets/fonts/FONT-LICENSE.txt`.
