Приложение помогает быстро найти текст гимна дома, на богослужении или в дороге. Все сборники и поиск находятся внутри приложения — интернет не нужен вообще.

## Что есть в приложении

- **2 590 песен в 7 сборниках** на русском и украинском языках.
- **Глобальный поиск** сразу по всем сборникам.
- **Поиск внутри выбранного сборника** по номеру, названию или фрагменту текста.
- **Аккорды** там, где они предусмотрены исходным материалом.
- **Настраиваемый размер текста** — от компактного до особенно крупного.
- **Светлая, тёмная и системная темы**.
- **Интерфейс на русском, украинском и английском** — язык выбирается по настройкам устройства.
- **Полностью автономная работа**: приложение никогда не обращается к интернету.

## Стек

- [Vue 3](https://vuejs.org/) и TypeScript;
- [Vite](https://vite.dev/) для разработки и web-сборки;
- [Capacitor](https://capacitorjs.com/) для мобильных платформ;
- BeerCSS и Tailwind CSS для интерфейса;
- Fuse.js в Web Worker для нечёткого поиска;
- TanStack Virtual для производительных длинных списков;
- petite-vue-i18n для локализации.

## Требования

- Node.js 24 (точная версия указана в `.nvmrc`);
- npm;
- для Android — Android Studio, Android SDK и JDK 21;
- для собственной iOS-версии — macOS и Xcode.
